# Lernplattform anbinden: Schritt-für-Schritt-Anleitungen

Kurze Anleitungen für die Einrichtung einer Moodle- oder ILIAS-Anbindung
(LTI 1.3). Jede Anleitung ist für eine Rolle und enthält nur die Schritte.
Hintergründe, Datenschutz, gespeicherte Daten und Fehlercodes stehen in der
Referenz [LMS integration (LTI 1.3)](../lms-integration.md).

| Wer | Anleitung | Dauer |
|---|---|---|
| Admin der Organisation in BenGER | [Organisations-Admin](org-admin.md) | 5 Minuten |
| ILIAS-Administration der Hochschule | [ILIAS-Administration](ilias-admin.md) | 10 Minuten |
| Moodle-Administration der Hochschule | [Moodle-Administration](moodle-admin.md) | 10 Minuten |
| Lehrende im Kurs | [Lehrende](teacher.md) | 5 Minuten |

**Reihenfolge**

1. Organisations-Admin: API-Schlüssel prüfen und **Lernplattform verbinden**
   starten.
2. LMS-Administration: das Tool in Moodle oder ILIAS eintragen.
3. Nur ILIAS: Organisations-Admin trägt Client ID und Deployment ID ein.
4. Lehrende: Aktivität im Kurs anlegen und eine Klausur verknüpfen.

Eine Klausurensammlung (Klausur mit mehreren Aufgaben) lässt sich in Moodle
und ILIAS Aufgabe für Aufgabe mit je einer Aktivität verknüpfen. Nur in
Moodle geht auch die ganze Sammlung in einer Aktivität, mit einer Spalte je
Aufgabe und dem Mittelwert in der Spalte der Aktivität. Dafür braucht das
Tool in Moodle die Spaltenverwaltung. Details stehen in der
[Anleitung für Lehrende](teacher.md).

Studierende brauchen keine Anleitung. Sie öffnen die Aktivität, stimmen einmal
zu und landen in der Klausur.
