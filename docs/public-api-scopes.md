| Scope | Description | Implies | Who may grant it |
|---|---|---|---|
| `org:read` | Read the organization and the key's own membership (Organisation und eigene Mitgliedschaft lesen) | - | `any` |
| `projects:read` | Read projects (Projekte lesen) | - | `any` |
| `tasks:read` | Read tasks (without reference solutions) (Aufgaben lesen (ohne Lösungshinweise)) | - | `any` |
| `tasks:read_reference` | Read tasks including reference solutions (Aufgaben mit Musterlösungen lesen) | `tasks:read` | `full_data_role` |
| `submissions:read` | Read submissions (Einreichungen lesen) | - | `any` |
| `submissions:write` | Create submissions (Einreichungen anlegen) | `submissions:read` | `any` |
| `systems:read` | Read registered systems (Registrierte Systeme lesen) | - | `any` |
| `systems:manage` | Register and manage systems (Systeme registrieren und verwalten) | `systems:read` | `any` |
| `runs:read` | Read runs (Läufe lesen) | - | `any` |
| `runs:write` | Create runs (Läufe anlegen) | `runs:read` | `any` |
| `evaluations:read` | Read evaluations (Evaluationen lesen) | - | `any` |
| `evaluations:run` | Start evaluations (Evaluationen starten) | `evaluations:read` | `any` |
| `results:read` | Read results (Ergebnisse lesen) | - | `any` |
| `exports:read` | Download exports (Exporte abrufen) | - | `any` |
| `keys:manage` | Manage the owner's own access keys (Eigene Zugangsschlüssel verwalten) | - | `personal_only` |

`grantable`: `any` (every key), `full_data_role` (personal keys and organization
keys with role CONTRIBUTOR), `org_admin` (organization keys created by an
organization admin), `personal_only` (personal keys only).
